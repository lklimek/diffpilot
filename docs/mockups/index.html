diffpilot mockups: tour-only variant

Static HTML. One example PR: acme/node-client #482 “feat(rpc): retry with backoff on timeout” (Rust, head 9f3c2e1). The review screen is the tour; the Groups workspace is left for a later version. Follows decisions-after-mockup-round-1.md, section L.

  1. 01 Home — one field; states: new PR, resume existing analysis, head moved, error, signed out.
  2. 02 Analysis progress — one progress bar with Cancel; states: running, paused, failed, finished (Open review).
  3. 05 Tour (the review screen) — PR context first; then per flow an introduction and its steps, one block at a time; flow diagram on demand; inspector and comments. States: 1 confident but wrong HIGH, 2 defect on a plain changed line, 3 LLM raised no questions, no project profile, returning to an interrupted review.
  4. 09 Settings — credentials status, language, GitHub App, read-only repository rules.
  5. 10 PR page and Comments (proposed) — processing PR review comments (docs/review-workflow-plan.md, ADR-023); state switcher: My work with Watch, watched PRs, Settings › Notifications (browser, ntfy, webhook), PR page (plain and watched), review menu with Comments, question cards (context, gate, phase 3, re-asked repeat, group, decide the rest, round-3 merge, dismiss stale reviews, assessment running), table page, rounds, carry-overs, decision log and agents (with push targets), empty, GitHub error.

Press ? for keyboard shortcuts and the legend. Light and dark follow the system. No network requests are made; links to github.com open in a new tab.

How code is drawn

  • changed line: neutral bar in the gutter (deterministic, from the diff)
  • HIGH: solid bar · MEDIUM: dashed bar · LOW or affected: dotted bar (colour = LLM rating, only on annotated ranges)
  • A changed line without colour has no LLM remark.
  • moved, text identical: double bar · ≠ line differs from the moved original
  • outside the diff, unchanged · removed code shown at the deletion marker
  • ◆ LLM remark · ▣ your comment
