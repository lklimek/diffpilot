smart-review

Review a GitHub pull request by what the change does, not by which lines moved.

Sign in with GitHub

The tool reads the PR with your own GitHub access. It never submits a review for you.

Which pull request?

Example: https://github.com/owner/repo/pull/123

What happens after Analyze

  1. The agent reads the PR and plans the flow groups.
  2. You can open a group as soon as it is analysed.
  3. Comments you write go straight into your GitHub pending review; you submit it on GitHub.

An existing analysis of the same PR is resumed instead of started again.

How code is drawn

  • changed line: neutral bar in the gutter (deterministic, from the diff)
  • HIGH: solid bar · MEDIUM: dashed bar · LOW or affected: dotted bar (colour = LLM rating, only on annotated ranges)
  • A changed line without colour has no LLM remark.
  • moved, text identical: double bar · ≠ line differs from the moved original
  • outside the diff, unchanged · removed code shown at the deletion marker
  • ◆ LLM remark · ▣ your comment
